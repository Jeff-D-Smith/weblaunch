WebLaunch

WebLaunch is a focused web app launcher designed to open a dedicated web application in a clean, controlled app experience.

Features

  • Launch a saved dedicated web app
  • Set a custom App Title and Base URL
  • Show or hide navigation controls
  • Clear cache, cookies, website data, and navigation history
  • Open temporary web app links without overwriting saved settings

Default Settings Mode

When WebLaunch opens normally, it uses your saved settings:

  • Base URL - The main web app WebLaunch opens.
  • App Title - The title shown inside the app.
  • Navigation Buttons - Optional Back, Forward, Refresh, and Home controls.

These settings are managed inside the app using the Settings screen.

Temporary Link Mode

WebLaunch can also be opened using special links. These are useful for emails, QR codes, documentation, intranet pages, or MDM deployments.

Temporary links open immediately and do not overwrite the saved Base URL, App Title, or navigation setting.

weblaunch://open?url=https%3A%2F%2Fportal.company.com

Temporary Link Options

Temporary links may also include a temporary title and navigation setting:

weblaunch://open?url=https%3A%2F%2Fportal.company.com&name=HR%20Portal&nav=false
  • url - Required. The web application URL to open.
  • name - Optional. Temporary title shown while the link is open.
  • nav - Optional. Use true or false to show or hide navigation buttons.
Closing and reopening WebLaunch normally returns to the saved Base URL.

Getting Started

Open Settings in the app and enter your saved web app URL:

https://portal.company.com

Privacy Policy

WebLaunch respects your privacy. This app is designed to provide a simple, focused way to access a web application and does not collect personal data.

Data Collection

WebLaunch does not collect, store, or transmit personal information.

Browsing Data

Any websites accessed through WebLaunch are loaded directly on your device using standard web technologies. WebLaunch does not monitor, record, or store browsing activity.

Third-Party Websites

WebLaunch allows access to external websites. These websites are not operated by WebLaunch and may collect data according to their own privacy policies. You are encouraged to review the privacy policies of any websites you visit.

Local Data

WebLaunch may store basic configuration settings locally on your device, such as the selected web app URL and app preferences. This data is not shared or transmitted.
