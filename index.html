WebLaunch

WebLaunch is a focused web app launcher designed to open a single web application in a clean, controlled experience.

Features

  • Launch a dedicated web app
  • Optional navigation controls
  • Clear cache and browsing data
  • Deep link configuration support

Getting Started

Open Settings in the app and enter your web app URL:

https://portal.company.com

Deep Linking

WebLaunch supports configuration via link:

weblaunch://open?url=https%3A%2F%2Fportal.company.com
